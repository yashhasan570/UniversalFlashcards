# Installing Universal Flashcards

## Running directly

To run without installing, change to this folder in a terminal, and run the
following command:

./universalflashcards

## Installing

To install system wide, run 'sudo ./install.sh'

To remove in the future, run 'sudo /usr/local/share/universalflashcards/uninstall.sh'.

## Audio

To play and record audio, mpv and lame must be installed. If mpv is not
installed or too old, Universal Flashcards will try to fall back on using mplayer.

## Problems

If Universal Flashcards fails to start, please run it from a terminal to see what errors it
outputs, and then post on our support site.
