# Universal Flashcards

Spaced-repetition flashcard program that helps you remember information long-term: cards, decks, scheduling, and sync across devices.

## Features

- Spaced repetition scheduling (FSRS scheduler built in)
- Cards with rich text, images, audio, LaTeX, and cloze deletions
- Deck options, filtered decks, and exam-style cramming
- Add-ons and JavaScript API for extensions
- Sync between desktop and mobile devices (self-hostable sync server included)

## Install

- Download a prebuilt binary from the releases page (Windows/macOS/Linux)
- Build from source: see `build/README.md` (Rust + Python + Node toolchain)
